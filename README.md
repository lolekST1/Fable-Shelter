# Fable Shelter

Idle-arcade phone game about a shelter for fairy-tale creatures. Prototype scene: Three.js + TypeScript + Vite.

```
npm install
npm run dev
```

Live: https://fable-shelter.vercel.app (every push to `main` deploys).

- `CLAUDE.md`: project context, design decisions, debug hooks
- `docs/PROMPTY.md`: image prompts for all characters and props
- `tools/`: model pipeline (gltf-transform, eye/lid detection) and Playwright tests
